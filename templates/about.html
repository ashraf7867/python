🐍 Built with Python

This web application is built using Python and the Flask web framework, making it lightweight and easy to extend.

📝 Task Management

Create, complete, and delete tasks with a simple and intuitive interface. Keep track of when tasks were created.

📱 Responsive Design

The application works great on desktop, tablet, and mobile devices with a responsive design.

🔧 REST API

Includes a simple REST API endpoint at /api/tasks that returns tasks in JSON format.

Technology Stack

  • Backend: Python 3.x with Flask framework
  • Frontend: HTML5, CSS3, JavaScript (vanilla)
  • Storage: In-memory storage (for demo - use database in production)
  • Templating: Jinja2 (Flask's default template engine)
  • Styling: Custom CSS with modern gradients and animations

Getting Started

1. Install Flask:

pip install flask

2. Run the application:

python app.py

3. Open your browser:

http://localhost:5000

  • Implement task due dates and reminders
  • Add task priority levels
  • Include task search and filtering
  • Add task editing capabilities
  • Implement task sharing between users
